# Agent Chat project context

Before working in this project, read:

1. `CHAT-CONTEXT.md` — conversation record, user decisions, and handoff state.
2. `noctalia-agent-chat-plan.md` — detailed implementation plan and acceptance criteria.

The project is a native Noctalia desktop chat plugin with selectable backends: the user's existing OpenCode installation or Codex directly through app-server. It is for quick general chat and laptop assistance, not project coding. Read the scope update at the top of the plan: it supersedes the original OpenCode-only architecture. Compatibility findings are in `COMPATIBILITY.md` and `CODEX-COMPATIBILITY.md`. Direct Codex stdio discovery works; shared-daemon transport and end-to-end lifecycle remain unresolved. Both backends require model selection.
